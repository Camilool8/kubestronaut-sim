## Question

Какое сетевое поведение имеет pod с hostNetwork: true?

## Options

- Теряет внешнюю связность
- Как обычно получает IP из pod CIDR
- Взаимодействует только с pods того же namespace
- Разделяет сетевое пространство имён узла и использует IP узла

## Solution

**Разделяет сетевое пространство имён узла и использует IP узла** — правильный ответ: При `hostNetwork: true` pod не получает собственного netns: он использует IP и интерфейсы узла. Открытые порты конкурируют с процессами хоста, а NetworkPolicies на основе podSelector обычно применяются не так, как ожидается.
