## Question

Что делает externalTrafficPolicy: Local у Service типа LoadBalancer/NodePort?

## Options

- Перенаправляет только на локальные endpoints узла, сохраняя IP клиента
- Ограничивает доступ клиентами из той же подсети
- Принудительно включает режим IPVS
- Отключает балансировку и отправляет всё на первый endpoint

## Solution

**Перенаправляет только на локальные endpoints узла, сохраняя IP клиента** — правильный ответ: При `Local` узел перенаправляет трафик только на локальные pods. SNAT не выполняется, поэтому сохраняется реальный IP клиента. Узлы без endpoints исключаются из LB через healthCheckNodePort. При `Cluster`, используемом по умолчанию, возможен второй hop с SNAT.
