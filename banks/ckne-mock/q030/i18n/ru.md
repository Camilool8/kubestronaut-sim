## Question

Какой подход используется, чтобы напрямую представить сети pods физической сети компании без NAT и сделать IP pods маршрутизируемыми?

## Options

- Создать отдельный NodePort для каждого pod
- Объявлять pod CIDRs через BGP
- Включить hostNetwork у всех pods
- Увеличить ndots в resolv.conf

## Solution

**Объявлять pod CIDRs через BGP** — правильный ответ: CNI с поддержкой BGP устанавливают sessions с маршрутизаторами и объявляют podCIDRs каждого узла. Внешняя сеть изучает маршруты и достигает pods напрямую, без инкапсуляции/NAT.
