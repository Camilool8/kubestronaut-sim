## Question

При использовании Multus с вторичными сетями на нескольких узлах почему IPAM whereabouts предпочтительнее host-local?

## Options

- host-local требует внешний DHCP
- host-local распределяет IP отдельно на каждом узле без координации и может создавать дубликаты
- Он быстрее при каждой операции CNI ADD и DEL
- whereabouts поддерживает только IPv6

## Solution

**host-local распределяет IP отдельно на каждом узле без координации и может создавать дубликаты** — правильный ответ: `host-local` хранит состояние только на диске узла, поэтому два узла могут выдать одинаковый IP во вторичной сети. `whereabouts` сохраняет allocations в CRDs кластера и гарантирует уникальность всего диапазона между всеми узлами.
