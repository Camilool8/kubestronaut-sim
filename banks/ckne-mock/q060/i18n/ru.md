## Question

Что ожидается увидеть в `ip route` на узле при CNI в режиме native routing без инкапсуляции?

## Options

- Маршруты к podCIDRs других узлов через IP соседнего узла
- Маршруты /32 к каждому pod всего кластера
- Никаких маршрутов, связанных с pods
- Только default route на физический gateway

## Solution

**Маршруты к podCIDRs других узлов через IP соседнего узла** — правильный ответ: В режиме direct/native routing пакеты не инкапсулируются: каждый узел должен знать, что podCIDR соседнего узла доступен через IP этого узла. Маршруты устанавливает CNI или они изучаются через BGP. Их отсутствие нарушает cross-node трафик.
