## Question

افتراضياً، عندما يتصل pod بوجهة خارج الكلاستر، ما التحويل الذي يحدث للحركة عند مغادرة العقدة؟

## Options

- لا تحويل لأن IP الخاص بـ pod قابل للتوجيه دائماً عبر الإنترنت
- تتحول إلى IPv6
- SNAT أو masquerade بحيث يصبح IP المصدر هو IP العقدة
- تُحجب الحركة افتراضياً

## Solution

**SNAT أو masquerade بحيث يصبح IP المصدر هو IP العقدة** هي الإجابة الصحيحة: تطبق CNIs عادة masquerade على الوجهات خارج cluster CIDRs، لذلك يرى الخادم الخارجي IP العقدة. يمكن تعديل ذلك عبر أدوات مثل `ip-masq-agent` عندما تكون عناوين pods قابلة للتوجيه في شبكة الشركة.
