## Question

Какое преобразование по умолчанию проходит трафик pod при выходе с узла к назначению вне кластера?

## Options

- Никакого — IP pod всегда маршрутизируется в интернете
- Трафик преобразуется в IPv6
- SNAT/masquerade: исходный IP становится IP узла
- Трафик блокируется по умолчанию

## Solution

**SNAT/masquerade: исходный IP становится IP узла** — правильный ответ: CNI применяют masquerade для назначений вне CIDRs кластера, поэтому внешний сервер видит IP узла. Это можно настроить, например через `ip-masq-agent` с nonMasqueradeCIDRs, если IP pods маршрутизируются в корпоративной сети.
