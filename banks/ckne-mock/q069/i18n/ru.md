## Question

Приложения жалуются на медленное разрешение внешних имён, например api.github.com, из pods. tcpdump показывает несколько запросов NXDOMAIN перед правильным ответом. Каковы причина и устранение?

## Options

- CoreDNS повреждён и отвечает с задержкой
- TTL записи равен нулю
- Расширение ndots:5 через search domains; используйте FQDN с завершающей точкой
- Недостаточная пропускная способность между узлами и CoreDNS

## Solution

**Расширение ndots:5 через search domains; используйте FQDN с завершающей точкой** — правильный ответ: При `ndots:5` имя с менее чем пятью точками сначала расширяется всеми search domains, создавая 3–5 дополнительных запросов NXDOMAIN. Завершающая точка принудительно задаёт абсолютный запрос; `dnsConfig.options ndots:1` меняет поведение для конкретного pod.
