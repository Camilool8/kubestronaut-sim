## Question

Каково главное ограничение режима L2 (ARP) для объявления LoadBalancer, например MetalLB L2/Cilium L2 Announcements?

## Options

- Требуется коммерческая лицензия MetalLB Enterprise
- Весь трафик одного VIP входит через ОДИН выбранный узел
- Поддерживается только UDP, но не TCP
- Режим не работает с IPv4 и поддерживает только dual-stack IPv6

## Solution

**Весь трафик одного VIP входит через ОДИН выбранный узел** — правильный ответ: В L2 один узел отвечает ARP за VIP. Входящая пропускная способность ограничена этим узлом, а failover зависит от gratuitous ARP и может дать несколько секунд недоступности. BGP+ECMP устраняет оба ограничения и предпочтителен в production.
