## Question

Какова сетевая политика по умолчанию между pods в кластере, где НЕ применены NetworkPolicies?

## Options

- Разрешён только трафик внутри одного namespace
- Разрешён только TCP
- По умолчанию всё заблокировано
- Любой трафик между любыми pods разрешён — allow-any-any

## Solution

**Любой трафик между любыми pods разрешён — allow-any-any** — правильный ответ: Сетевая модель Kubernetes по умолчанию открыта: без policies изоляции нет. Поэтому рекомендуется начинать с default-deny в каждом namespace и явно разрешать только необходимое.
