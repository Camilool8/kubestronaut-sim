## Question

Как разрешить ДИАПАЗОН портов, например 30000–32767, в одном rule NetworkPolicy?

## Options

- NetworkPolicy не поддерживает диапазоны
- Использовать protocol RANGE
- Перечислить все 2768 портов по одному в нескольких rules
- Использовать port: 30000 и endPort: 32767 в одной записи

## Solution

**Использовать port: 30000 и endPort: 32767 в одной записи** — правильный ответ: Поле `endPort` задаёт конец диапазона, начинающегося с `port`; порт должен быть числовым, не именованным. Возможность стабильна с Kubernetes 1.25.
