## Question

Два контейнера ОДНОГО pod пытаются слушать порт 8080. Что произойдёт?

## Options

- Это работает: у каждого контейнера свой network namespace
- kubelet создаст второй IP
- Трафик будет балансироваться между ними
- Второй процесс завершится с ошибкой address already in use

## Solution

**Второй процесс завершится с ошибкой address already in use** — правильный ответ: Network namespace принадлежит sandbox-контейнеру pause; все контейнеры pod используют его совместно. Поэтому они могут обращаться друг к другу через localhost, но также конфликтуют за одни и те же порты.
