## Question

Вы удалили и заново создали Service с тем же именем. Приложения, сохранившие старый IP, перестали работать. Какой архитектурный урок это подтверждает?

## Options

- Старый IP вернётся через 24 часа
- Нужно использовать IP pod напрямую
- Service нельзя пересоздавать
- ClusterIP может измениться при пересоздании Service

## Solution

**ClusterIP может измениться при пересоздании Service** — правильный ответ: IP динамически выделяется из service range при создании, если только он явно не закреплён через spec.clusterIP. Стабильный контракт Kubernetes — ИМЯ. После пересоздания также учитывайте кэш DNS на стороне приложений, особенно JVM.
