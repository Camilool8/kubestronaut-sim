## Question

Вы настроили weighted canary 90/10 И отдельное направление заголовка x-beta: true на v2. Пользователь с x-beta: true иногда попадает на v1. Что проверить?

## Options

- Браузер удаляет заголовки
- Gateway API не поддерживает header match
- Не находится ли header match в ТОЙ ЖЕ rule, что и веса
- Вес всегда имеет приоритет над заголовками

## Solution

**Не находится ли header match в ТОЙ ЖЕ rule, что и веса** — правильный ответ: Ловушка структуры: canary по заголовку должен быть отдельной, более специфичной rule. Rule только с весами остаётся fallback. Если смешать match и веса в одной rule, пользователь всё равно участвует во взвешенной лотерее.
