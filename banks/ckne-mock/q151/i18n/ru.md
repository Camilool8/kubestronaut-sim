## Question

Два кластера с ОДИНАКОВЫМИ pod CIDR, оба 10.244.0.0/16, должны соединиться через Submariner. Возможно ли это?

## Options

- Только если один кластер использует IPv6
- Нет, перекрывающиеся CIDR исключают любое соединение
- Да, с Globalnet: виртуальные CIDR и межкластерный NAT
- Да, без какой-либо настройки

## Solution

**Да, с Globalnet: виртуальные CIDR и межкластерный NAT** — правильный ответ: Перекрывающиеся CIDR мешают прямой маршрутизации. Submariner Globalnet создаёт виртуальные globalCIDR и выполняет ingress/egress NAT — это специальное решение для существующих сред с повторяющимися диапазонами.
