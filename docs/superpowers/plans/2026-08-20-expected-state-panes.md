# Expected-state panes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every failed check on the explanation screen shows the candidate's cluster state beside a generated expected document, or declares in the check file why it cannot.

**Architecture:** Each check gains an unconditional `snapshot()` holding the projection it already builds inline, and a `# expected: <name> <lang>` header (or `# expected: none — <reason>`). One new library function, `show_pair`, feeds both panes from that single pipeline. Documents are generated by running `snapshot()` against a cluster the grader just scored at full marks — never hand-written — via two new modes of `tests/drill.sh`. An offline gate makes every one of the 212 decisions visible; two live gates make the documents provably reproducible and prove each pane pair actually diverges before the work is done.

**Tech Stack:** bash (`banks/_lib/checks.sh`, the check bank, the test gates), Python 3 (the offline gate, matching `tests/check-lint.sh`), TypeScript/React + vitest (the Explain screen). No Go changes: the grader parses only `# points: ` and `# desc: ` (`facilitator/internal/exam/exam.go:437-438`), so the new header is an ordinary comment to it.

**Spec:** `docs/superpowers/specs/2026-08-20-expected-state-panes-design.md`

**The library code in Tasks 1 and 2 was prototyped and run before this plan was written.** Verified against a patched copy of `checks.sh`: `show_pair` emits both panes from one pipeline; an empty snapshot keeps the declared language while `show_actual` still degrades to `text`; the `EXIT` trap fires on a check that ends in `exit 1` and preserves that exit code; artifacts are silenced under `SIM_CAPTURE_EXPECTED` while a normal run emits no capture block; a check with no `snapshot()` captures silently; and the `declared_docs` awk parser returns one row for a paired check and none for an opt-out or an undeclared check.

## Global Constraints

- **No AI attribution in commits.** Omit `Co-Authored-By` and `Claude-Session` trailers and the PR footer. This repository's rule overrides the harness default.
- **Never hand-write an `expected/` document.** They are generated from the reference solution (`docs/bank-spec.md:616-619`). A hand-written one drifts from what `tests/solutions/<bank>/<qid>.sh` produces and then teaches the candidate something false.
- **A projection shows only what its check grades**, and is canonicalised — `jq -S` for key order, scalar arrays sorted where order carries no meaning, `k8s_clean` for YAML. A whole-object pane marks an equally-correct answer as wrong.
- **Grader deny-list still applies** (`tests/check-lint.sh`): no `diff`, no grep-on-YAML, no `kubectl -o yaml` outside `k8s_clean`, no `kubectl run`, no `grep -x`, no `[0]` indexing, `report` last.
- **Never grade or capture resume-fragile state**: Pod IPs, restart counts, controller-generated names, host port mappings, uids, creationTimestamps.
- **Checks execute on instance-1/instance-2 only**, API reads only, 30 s budget. The one documented node-read exception is `cka-mock-01/q26`'s snapshot-file check.
- **Bank ids are `cka-mock-01` and `ckad-mock-01`.** Never `cka-mock`.
- Agents do not run `git`, `./sim`, or `docker compose`. The lead reviews each diff, runs the gates, and commits.
- `banks/_lib/checks.sh` is sourced, never executed; it carries `# shellcheck shell=bash` and no shebang.
- Every `bash` file added or changed must pass `bash tests/check-shell.sh` and `sh tests/check-line-endings.sh`.

In `banks/_lib/checks.sh`, replace `_artifact` (`:82-88`) with a version that can be told to keep the caller's language:

```bash
_artifact() {
  local body=$3
  case "$(printf '%s' "$body" | tr -d '[:space:]')" in
    ''|null)
      body=$ARTIFACT_EMPTY
      # show_actual degrades to `text`, because a bare sentence tagged `json`
      # is a lie about its own contents. show_pair passes keep-lang instead:
      # its placeholder sits beside an EXPECTED pane in the declared language
      # and the two headings have to read as one comparison.
      [ -n "${4:-}" ] || set -- "$1" text "$body"
      ;;
  esac
  printf '%s %s %s\n%s\n' '---8<--- sim:artifact' "$1" "$2" "$body"
}
```

Then add, immediately after `show_expected` (`:102-105`):

```bash
# A check's expected document sits beside the check, at <qid>/expected/<name>,
# and the path is derived from the script's own location rather than spelled
# out. A literal "/banks/${BANK:-cka-mock-01}/q15/expected/..." names a bank to
# fall back to — the wrong one for every bank but that one — and repeats the
# qid in a string, which is exactly the copy-paste that goes wrong when a
# question directory is duplicated to start the next question.
#
# tests/check-evidence.sh runs a REWRITTEN copy of a check out of a temp
# directory, so $0 there points at the copy; it exports SIM_CHECK_PATH with the
# real path. Nothing in production sets it — the grader invokes the script at
# its own path (facilitator/internal/evaluate/evaluate.go:95).
expected_dir() {
  local p=${SIM_CHECK_PATH:-$0}
  printf '%s/expected' "$(dirname "$(dirname "$p")")"
}

# Both panes, from one pipeline.
#
# The actual side is the check's own snapshot(); the expected side is the
# document generated by running that same snapshot() against a solved cluster.
# One function feeds both, so "filter both panes identically"
# (docs/bank-spec.md) stops being something an author has to remember and
# becomes the only way to write it.
show_pair() {
  _artifact actual "$1" "$(snapshot)" keep-lang
  show_expected "$1" "$(expected_dir)/$2"
}
```

```bash
# ---------------------------------------------------------- expected capture
#
# An expected document is generated by running the check's own snapshot()
# against a solved cluster, never hand-written. That cannot ride on the
# evidence path, for two independent reasons: a check that PASSES loses its
# artifacts entirely (docs/bank-spec.md), so on a solved cluster the emitters
# produce nothing at all; and evidence() is only ever reached from a failure
# branch anyway.
#
# So capture is an EXIT trap. It fires after the check's body has run, with
# every variable the check set still in scope, which is what lets snapshot()
# re-use the reading the check already took rather than going back to the API
# for a second, drifting opinion of it. Bash resolves the function at fire
# time, so snapshot() may be declared anywhere below this line. No validate
# script in either bank installs a trap of its own.
SIM_CAPTURE_SENTINEL='---8<--- sim:capture'

_capture_emit() {
  declare -F snapshot >/dev/null 2>&1 || return 0
  printf '%s\n%s\n' "$SIM_CAPTURE_SENTINEL" "$(snapshot)"
}

if [ -n "${SIM_CAPTURE_EXPECTED:-}" ]; then
  trap '_capture_emit' EXIT
fi
```

  # catches show_pair too, which reaches _artifact directly.
  [ -z "${SIM_CAPTURE_EXPECTED:-}" ] || return 0

  ...

Create `tests/check-expected.sh`:

```bash
#!/usr/bin/env bash
# Every check either pairs its evidence with a generated expected document, or
# says in the file why it cannot.
#
# Before this gate, 193 of 212 checks showed the candidate their own cluster
# state and a paragraph telling them to go read the reference solution — and
# nothing anywhere recorded whether that was a decision or an omission. The
# two must not look alike, so the declaration is required and a `none` carries
# its reason.
#
#   bash tests/check-expected.sh [root]     # root defaults to the repo
set -euo pipefail
cd "$(dirname "$0")/.."

python3 - "${1:-.}" <<'PY'
import pathlib, re, sys

root = pathlib.Path(sys.argv[1])
scripts = sorted(root.glob("banks/*/q*/validate.d/*.sh"))
if not scripts:
    print(f"check-expected: found no validate.d scripts under {root} — refusing to pass")
    sys.exit(1)

DECL = re.compile(r"^#\s*expected:\s*(.+?)\s*$", re.M)
SNAP = re.compile(r"^\s*snapshot\s*\(\)", re.M)
PAIR = re.compile(r"^\s*show_pair\s+(\S+)\s+(\S+)", re.M)

problems = []
declared = {}   # (question dir, document name) -> the check that declared it
paired = optout = 0

for s in scripts:
    text = s.read_text()
    rel = s.relative_to(root)
    decls = DECL.findall(text)

    if not decls:
        problems.append(f"{rel}: no '# expected:' declaration. Add "
                        "'# expected: <name> <lang>' beside the '# points:' header, or "
                        "'# expected: none — <why this check has no comparable document>'")
        continue
    if len(decls) > 1:
        problems.append(f"{rel}: {len(decls)} '# expected:' declarations — a check pairs at most one document")
        continue

    decl = decls[0]
    has_snap = bool(SNAP.search(text))
    pair = PAIR.search(text)

    if decl.split()[0] == "none":
        optout += 1
        reason = decl[len("none"):].lstrip(" —-").strip()
        if not reason:
            problems.append(f"{rel}: opts out but gives no reason. Write "
                            "'# expected: none — <why>'; an unexplained opt-out is "
                            "indistinguishable from a check nobody looked at")
        if has_snap:
            problems.append(f"{rel}: opts out but defines snapshot() — delete it, or pair the check")
        if pair:
            problems.append(f"{rel}: opts out but calls show_pair — the two contradict each other")
        continue

    parts = decl.split()
    if len(parts) != 2:
        problems.append(f"{rel}: '# expected: {decl}' — want exactly '<name> <lang>'")
        continue
    name, lang = parts
    paired += 1

    if not has_snap:
        problems.append(f"{rel}: declares {name} but defines no snapshot() to generate it from")
    if not pair:
        problems.append(f"{rel}: declares {name} but never calls show_pair, so the pane is never shown")
    else:
        plang, pname = pair.group(1), pair.group(2)
        if plang != lang:
            problems.append(f"{rel}: declares lang '{lang}' but show_pair passes '{plang}'")
        if pname != name:
            problems.append(f"{rel}: declares {name} but show_pair reads {pname}")

    doc = s.parent.parent / "expected" / name
    if doc.exists():
        declared[(s.parent.parent, name)] = rel
    else:
        problems.append(f"{rel}: declares {name} but {doc.relative_to(root)} does not exist. "
                        "Generate it with 'bash tests/drill.sh --capture <bank>' — never by hand")

for qdir in sorted({s.parent.parent for s in scripts}):
    for doc in sorted((qdir / "expected").glob("*")):
        if doc.is_file() and (qdir, doc.name) not in declared:
            problems.append(f"{doc.relative_to(root)}: no check declares it. Delete it, or "
                            "add '# expected: {} <lang>' to the check it belongs to".format(doc.name))

for p in problems:
    print(f"check-expected: {p}")
print(f"check-expected: {len(scripts)} checks — {paired} paired, {optout} declared none, "
      f"{len(problems)} problems")
sys.exit(1 if problems else 0)
PY
```

```bash
# qid -> "<script>\t<name>\t<lang>" per check that declares a document.
# Opt-outs produce no row, so they are skipped by declaration rather than by
# a failure the operator has to read past.
declared_docs() {
  local f base
  for f in "banks/${BANK}/$1"/validate.d/*.sh; do
    [ -f "$f" ] || continue
    base=$(basename "$f")
    awk -v s="$base" '
      /^#[[:space:]]*expected:/ {
        sub(/^#[[:space:]]*expected:[[:space:]]*/, "")
        if ($1 != "none") print s "\t" $1 "\t" $2
        exit
      }' "$f"
  done
}

# Run one check with capture on and return only what the trap emitted. The
# env is the grader's own (facilitator/internal/evaluate/evaluate.go:95) so the
# check reads the same cluster through the same kubeconfig it is graded with.
capture_one() { # qid instance script
  docker compose exec -T "$2" env SIM_CAPTURE_EXPECTED=1 \
    KUBECONFIG=/home/candidate/.kube/config "BANK=${BANK}" \
    bash "/banks/${BANK}/$1/validate.d/$3" 2>/dev/null \
    | awk 'f {print} /^---8<--- sim:capture$/ {f=1}'
}

capture_question() { # qid instance
  local qid=$1 inst=$2 script name lang body path
  while IFS=$'\t' read -r script name lang; do
    [ -n "$script" ] || continue
    body=$(capture_one "$qid" "$inst" "$script")
    case "$(printf '%s' "$body" | tr -d '[:space:]')" in
      ''|null)
        fail "${qid}/${script}: captured nothing for ${name} — the check exited before its snapshot, or the cluster is not actually solved"
        continue ;;
    esac
    path="banks/${BANK}/${qid}/expected/${name}"
    if [ "$MODE" = capture ]; then
      mkdir -p "$(dirname "$path")"
      printf '%s\n' "$body" > "$path"
      echo "    wrote ${path}"
    elif [ ! -f "$path" ]; then
      fail "${qid}/${script}: declares ${name} but ${path} does not exist — run --capture"
    elif [ "$(cat "$path")" != "$body" ]; then
      fail "${qid}/${script}: ${name} is stale — the check's snapshot no longer matches the committed document"
    fi
  done <<< "$(declared_docs "$qid")"
}

# A pane pair that already matches before the candidate has done anything is
# proving nothing: the projection does not cover what the check grades, and the
# candidate would be shown two identical documents beside a failed check.
divergence_question() { # qid instance
  local qid=$1 inst=$2 script name lang path
  while IFS=$'\t' read -r script name lang; do
    [ -n "$script" ] || continue
    path="banks/${BANK}/${qid}/expected/${name}"
    [ -f "$path" ] || continue
    if [ "$(cat "$path")" = "$(capture_one "$qid" "$inst" "$script")" ]; then
      fail "${qid}/${script}: ${name} already matches on the unsolved cluster — the projection does not cover what the check grades"
    fi
  done <<< "$(declared_docs "$qid")"
}
```
